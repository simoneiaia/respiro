# Firebase (gratuito) per Respiro

## URL

| Servizio | URL |
|----------|-----|
| App | https://respiro-benessere.web.app |
| Console | https://console.firebase.google.com/project/respiro-benessere |

Il nome in app è **respiro.web.app**; l’indirizzo reale resta `respiro-benessere.web.app` (ID progetto Firebase).

## Deploy

```bash
npm run deploy
```

Variabili in `.env.production.local` (non committato).
